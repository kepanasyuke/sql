# csv-profiler — профилирование данных и поиск PII

Профилировщик CSV, который превращает «данные как-то выглядят» в измеримые
факты: типы колонок, доля NULL, количество уникальных значений, границы и
квантили, найденные персональные данные. На выходе — markdown-профиль и
**заготовки DQ-проверок с уже подобранными порогами**.

## Что умеет

- **вывод типа** по значениям (`integer`, `number`, `date`, `boolean`, `text`),
  смешанная колонка честно помечается как `text`;
- **полнота**: число и доля NULL по каждой колонке;
- **уникальность с ограничением памяти**: distinct считается до 200 значений,
  дальше колонка помечается `distinct_capped` (на 10 млн строк это принципиально);
- **распределение**: min/max и p50/p95 по числовым колонкам;
- **PII**: ИНН с проверкой контрольного числа, номер карты по алгоритму Луна,
  телефон, e-mail — и маскирование примеров в отчёте;
- **генерация проверок**: complete ness для колонок с NULL, uniqueness для
  кандидатов в бизнес-ключ, range по p95 — в формате каталога DQ.

## Запуск

```bash
python -m projects.csv_profiler.cli demo-csv --output artifacts/demo.csv
python -m projects.csv_profiler.cli profile --file artifacts/demo.csv \
    --entity mart.clients --markdown artifacts/profile.md --checks artifacts/checks.json
python -m projects.csv_profiler.cli profile --demo
```

## Зачем это в сопровождении данных

Порог проверки, придуманный «на глаз», либо не срабатывает никогда, либо
падает каждую ночь. Профиль даёт факты: если NULL в сегменте 25%, то `warn`
ставится на 25%, а `fail` — на 43% (двойной запас). Такие пороги не нужно
пересматривать после каждой жалобы аналитика.

## Тесты

```bash
python -m pytest projects/csv_profiler -q
```

Проверяется: вывод типов (включая невалидную дату), контрольные числа ИНН и
Луна, определение и маскирование PII, доли NULL, квантили, ограничение
distinct, состав сгенерированных проверок и запись артефактов из CLI.

**В резюме:** «csv-profiler — профилирование данных: типы, полнота, квантили,
PII (ИНН/Луна/телефон), автогенерация DQ-проверок с порогами по распределению».
